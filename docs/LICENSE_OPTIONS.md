# Licensing: decision pending

No license file is included because the copyright holders' choice is not recorded in the project. This note lists options; it is not legal advice.

**Decide before publishing**

1. Who holds the copyright to the code (author, co-author, employer or university)? The project's earlier checklist also lists the question of rights to code created with the help of an AI assistant as open.
2. Which license (applies to the code only):
   * **MIT** or **BSD-3-Clause** — permissive, short; allows commercial reuse; requires keeping the notice.
   * **Apache-2.0** — permissive with an explicit patent grant; longer.
   * **GPL-3.0** — copyleft: derivative code must be released under the same terms.
   * **CC BY 4.0** is suitable for the aggregated result tables and the figure, not for software.
3. Several scripts are adapted from the project's own earlier files; the test for an earlier article's reference code was removed because that code is third-party and is not part of this repository.

**Data.** The Cresci-2017 data are not covered by any license here and must not be added. Their use is governed by the dataset authors' conditions (research use only, citation of the dataset paper, no redistribution of the original data).

After a decision, add `LICENSE` (and optionally `CITATION.cff`, once the authors, title and publication details are confirmed) and update the "License" section of `README.md`.
